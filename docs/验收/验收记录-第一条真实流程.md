## 2. 本地复现步骤

### 2.1 启动被测站点（必须用旧构建，端口 4000）

~~~powershell
cd "F:\SoftwareTest\期末大作业\静态博客网站测试"
python -m http.server 4000 --bind 127.0.0.1 --directory public
# 验证：curl http://127.0.0.1:4000/  应返回 200
~~~

### 2.2 启动后端（首次会自动建表并写入种子资产）

~~~powershell
$env:JAVA_HOME = "C:\Users\Lenovo\.jdks\ms-21.0.10"
$env:PATH = "$env:JAVA_HOME\bin;" + $env:PATH
cd "F:\SoftwareTest\期末大作业\TestPilot"
mvn -B -DskipTests "-Dmaven.repo.local=F:/SoftwareTest/.m2repo" spring-boot:run
# 验证：curl http://127.0.0.1:8080/api/v1/tool-assets?tool=APIFOX_CLI
~~~

> Maven 仓库指到 F:/SoftwareTest/.m2repo 是为了绕开 DSH 沙箱对 ~/.m2 的写限制；在普通本机终端用默认的 ~/.m2 也可以。若没有 mvn 可执行文件，用项目自带 mvnw.cmd（JAVA_HOME 必须指向 JDK 21）。

> 默认数据源为本机 MySQL 8.0.46：账号 root，密码写在本地 application.yaml（可用 DB_URL / DB_USERNAME / DB_PASSWORD 覆盖），库名 testpilot。首次启动由 schema.sql 自动建表（CREATE TABLE IF NOT EXISTS），工具资产由 application.yaml 的 testpilot.apifox.assets 自动登记。没有 MySQL 时用 -Dspring-boot.run.profiles=h2 回退到 H2 文件库。

### 2.3 启动前端

~~~powershell
cd "F:\SoftwareTest\期末大作业\TestPilot\frontend"
npm install     # 首次
npm run dev     # http://127.0.0.1:5173
~~~

### 2.4 从页面提交

1. 打开 http://127.0.0.1:5173/ ，点顶部导航「任务与报告」。
2. 点「新建任务」，在弹窗里：
   - 任务名称随意（本次为「页面验收-静态博客-低频只读」）；
   - 测试资产选「静态博客测试（Apifox 已登记场景，49 个只读 GET） · v1」（列表来自 GET /api/v1/tool-assets?tool=APIFOX_CLI，无本地演示兜底）；
   - 真实执行参数：iterations = 1、delayRequestMs = 100、timeoutRequestMs = 5000（低频、只读）。
3. 点「提交真实任务」。页面自动生成 uuid 幂等键，POST /api/v1/tasks 返回 202，随后 1.5 秒轮询状态。
4. 约 15 秒后状态变「断言失败（终态）」，通过 / 总数为 38 / 49。点「查看详情」可看概览、执行日志（536 行）、用例结果（49 条）、报告（12 项指标 + run.json / run.xml 查看与下载）。
5. 刷新页面（或复制 http://127.0.0.1:5173/?taskId=<任务ID> 重新打开、或在搜索框粘任务 ID 点「打开任务」）仍能看到同一任务。

### 2.5 用同一任务 ID 核对 CLI 原始报告

~~~powershell
# 后端把 CLI 的 JSON / JUnit 报告落在 data/reports/<taskId>/ 下
Get-Content "F:\SoftwareTest\期末大作业\TestPilot\data\reports\<taskId>\run.json" |
  ConvertFrom-Json | Select-Object -ExpandProperty result | Select-Object -ExpandProperty stats
~~~

也可复跑一次 CLI 做对照（与后端使用的参数完全一致）：

~~~powershell
C:\Users\Lenovo\AppData\Roaming\npm\apifox.cmd test-scenario run 8863397 --project 8941754 -e 49735657 ^
  -r cli,json,junit --out-dir "<某个空目录>" --out-file run -n 1 --delay-request 100 --timeout-request 5000 --color off
~~~

### 2.6 优雅关闭与重启后持久化验证

~~~powershell
curl -X POST http://127.0.0.1:8080/api/v1/admin/shutdown   # 上下文 close，H2 正常落盘，进程 exit 0
# 重新执行 2.2 启动后端，然后：
curl http://127.0.0.1:8080/api/v1/tasks/<taskId>          # 仍是 FINISHED / 38 通过 / 11 失败
~~~

> **H2 回退模式下不要用 taskkill /F、任务管理器结束进程或直接杀后台作业关闭后端**：实测 H2 2.4.240 与 2.3.232 在非正常终止后会把 .mv.db 永久置为只读（select readonly() 恒为 TRUE，复制文件也一样），只能删掉 data/ 重建。Ctrl+C 属于正常关闭，可以。MySQL 模式无此限制，但优雅关闭仍是推荐做法。

## 4. 11 条失败的归类（均为场景定义/客户端行为，非平台缺陷）

| 用例 | 页面显示 | 归类 | 原因 |
|---|---|---|---|
| case-038 标签：测试 | 断言失败 | 断言 | 步骤 37–40 的 URL 含中文，Apifox 不做 percent-encode，请求直接报 TypeError: Request path contains unescaped characters，随后的状态码断言拿到错误对象 → expected t{…} to have property 'code' |
| case-039 标签：技术 | 断言失败 | 断言 | 同上 |
| case-040 标签：杂谈 | 断言失败 | 断言 | 同上 |
| case-041 标签：杂谈第2页 | 断言失败 | 断言 | 同上 |
| case-043 RSS 订阅源 | 请求失败 · 该响应不应该有 Body | 请求 | 场景把响应定义为 noContent，实际站点返回 XML 正文 |
| case-044 Atom 订阅源 | 请求失败 · 该响应不应该有 Body | 请求 | 同上 |
| case-045 JSON Feed | 请求失败 · 该响应不应该有 Body | 请求 | 同上 |
| case-046 sitemap（预期缺失） | 请求失败 · 该响应不应该有 Body | 请求 | 同上 |
| case-047 robots（预期缺失） | 请求失败 · 该响应不应该有 Body | 请求 | 同上 |
| case-048 不存在路径（404 用例） | 请求失败 · 该响应不应该有 Body | 请求 | 404 页面返回 HTML 正文，场景声明 noContent |
| case-049 无尾斜杠（301 用例） | 请求失败 · 状态码 200 · HTTP 状态码错误 应该是 301, 实际却是 200 | 请求 | CLI 自动跟随重定向，看到最终 200；场景期望 301 |

要让 49/49 全绿必须改云端场景（noBody 改成声明正文、301 用例关闭自动跟随或改用 --ignore-redirects、中文路径换成已转义 URL）。本轮未获授权修改云端场景，验收按实际 38/49 记录。

## 5. 错误处理与契约一致性验证

| 场景 | 实测结果 |
|---|---|
| 缺 Idempotency-Key | 400，data.errors[{field: "Idempotency-Key"}] |
| 同键同内容重复提交 | 200，返回原任务当前摘要（不是新建） |
| 同键不同内容 | 409 IDEMPOTENCY_CONFLICT |
| iterations = 0 | 400 字段级错误（parameters.iterations） |
| 查询不存在的任务 | 404 NOT_FOUND |
| 站点未启动（工具执行失败） | 任务 FINISHED/FAILED，exitCode=1；results 49 条中 42 条 failureKind=REQUEST，日志里能看到 connect ECONNREFUSED 127.0.0.1:4000；页面对应行红字显示失败原因 |
| 取消 | QUEUED 直接 CANCELLED；RUNNING → CANCELLING 并结束进程树，随后转 CANCELLED；重复取消已取消返回 200，取消终态任务返回 409 TASK_NOT_CANCELLABLE |
| 报告未就绪 | 409 REPORT_NOT_READY；任务不存在 404 |
| 令牌脱敏 | CLI 会把本机登录令牌明文写进 run.json 的 options.accessToken；后端落盘前统一替换为 ***REDACTED-TOKEN***，实测下载与磁盘文件均无明文令牌 |
