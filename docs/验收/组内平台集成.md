# 组内平台集成验收 · 2026-11-13

本机 Windows、JDK 21、MySQL 8 testpilot 库、Spring Boot、Vue 生产构建、Edge、组长账号的 Apifox CLI。服务基线为 8080 后端、5173 开发前端、4000 被测静态博客均返回 HTTP 200，MySQL 在 3306 监听。升级前 8 条历史任务，无执行、排队或取消中的任务。升级使用原库。两轮真实验收后共 10 条任务。

## 八个入口的数据核对

| 入口 | 集成前 | 集成后 |
|---|---|---|
| 概览 | 已使用任务接口 | GET /tasks，task 汇总真实执行指标 |
| 网站与环境 | localStorage | /workspace 原子提交 sites、environments，写入 workspace_resource；支持单资源 /sites 和嵌套环境接口 |
| 测试资产 | 可执行场景读 tool_asset，本地资产和固定请求示例 | tool_asset 继续提供已登记执行场景；共享资产草稿及请求清单读 workspace_resource 的 assets、requests |
| 请求调试 | 浏览器生成模拟响应，本地保存请求 | POST /http-debug/executions 真实 HTTP；独立的本地模拟按钮。请求定义显式保存到 requests；调试会话里可载入历史定义 |
| 任务与报告 | Spring Boot、CLI、MySQL | task、task_log、task_result 和 data/reports；状态、增量日志、用例和脱敏报告延续原流程。演示归档在独立面板 |
| 实验对比 | 本地方案与工具体验，后端查询来源任务 | comparisons、comparisonExperiences、parameterPlans 共享；核对真实任务和报告；缺样本时列出缺项 |
| 断言回归 | 浏览器演示用例 | assertionCases 共享回归记录；任务断言明细来自 task_result |
| 检查验收 | 浏览器记录 | checks 共享保存步骤、预期、实际、证据位置、来源任务与复测记录 |

原始 localStorage 保留供用户主动迁移，正式共享工作区首次启动为空。实际请求运行使用组长配置的允许来源。当前组内模式没有成员账号和细分权限，按可信局域网部署。

## 其他验收结果

- 两个独立 Edge 会话分别新增、编辑同一网站，刷新读到对方改动。旧版本写入实际得到 409。删除后双方均不可见，所属环境也已删除。
- 旧版浏览器显式导入网站、环境、请求共 3 条，同一内容再次导入为 0 条。尝试删除仍被请求引用的网站时返回字段错误，数据库事务回滚。共享实验、工具体验、参数方案、回归和检查记录可查询，来源任务可定位。
- 重启前从页面保存请求资产 REQ-991619f5-1551-4400-99f6-3c92a6b55ed0，重启后在新会话的测试资产页面可见，单资源 API 返回同一 ID、revision=1。Windows 升级过程中重新打包正在运行的 JAR 导致优雅关闭失败，确认该 JVM 无活动任务后终止并重建；使用说明已给出先停止服务再打包的顺序。
- 真实 HTTP 使用临时回环接收端 18441：未登记网站直接 POST，接收端核对重复 Query、X-Probe、自定义 Cookie 及 JSON 正文，收到的请求不含平台 Authorization。目标返回 201，状态断言 PASSED。延迟应答显示 REQUEST_TIMEOUT，关闭接收端后显示 CONNECTION_ERROR。
- 前端 typecheck、生产构建、26 项 Vitest 通过。后端 Maven package 通过，Spring 上下文测试执行了 H2 建表；部署到原 MySQL 后表可读写并通过重启验证。最终两个核心 Playwright 文件共 7 项通过，覆盖八入口、窄屏、键盘、请求编辑、双会话、正常与异常流程。任务切换取消旧响应、终态停止轮询、游标和离页清理另有单元测试。
- 本机 WLAN 地址 http://192.168.5.197:8080/ 返回 200，通过同地址调用共享 API 返回 OK。未使用第二台物理电脑，物理网络与 Windows 入站规则需按使用说明最后一节由组员复核。
- 跨网站与 JMeter 对比仍需真实对照样本。调试历史为当前会话，模拟归档为演示功能，执行场景通过后端登记配置管理。
