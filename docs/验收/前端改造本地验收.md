## 后续交互问题修复（2026-11-12）

用户反馈：部分页面鼠标滚轮无效；新建网站从 JSON 切回逐字段填写时，被空名称校验阻止。实际复现发现，鼠标在表格内时 scrollY 不变，移到表格外则页面滚动；空网站 JSON 语法正确，但完整业务校验使模式切换失败。

修复：表格和日志仅限制横向滚动链，纵向滚轮可继续传递；侧栏允许在短视口滚动；弹窗以可视高度为上限，内容区滚动，标题和底部保存按钮保留。DualEditor 区分结构草稿解析与完整保存校验。网站名称、网址、任务参数未完成时允许返回表单。非法 JSON 也可退出，但不替换最近可编辑配置；原文保留，再次打开 JSON 可继续编辑，并提供显式从表单重新生成的操作。

本轮实际检查：19 项单元验证、7 组相关浏览器回归、vue-tsc 和生产构建通过。浏览器使用真实 mouse.wheel，覆盖网站/资产/任务/实验/回归/检查页表格上方的纵向滚动、390px 宽表横向滚动、1024×600 短视口长弹窗滚动、关闭弹窗后恢复页面滚动，以及网站/任务草稿往返与无效 JSON 原文保留。原有请求编辑、窄屏图表/日志/报告和实验方案保存一并回归。本轮未新建 CLI 执行任务。
