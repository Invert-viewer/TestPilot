## 1. 目标与当前进度

TestPilot 采用 Vue3 前端和 Spring Boot 后端，通过 REST API 配置、执行和查看测试。核心执行工具为 Apifox CLI，JMeter 用于对照实验。课程验收包括同一工具对两个同类网站的参数实验，以及两种工具对同一网站的比较。

| 核对位置 | 当前可确认的内容 |
|---|---|
| `pom.xml`、`src/main/` | Java 启动类、Web MVC、参数校验、MyBatis 和 MySQL 配置已就位。业务接口、数据表和工具执行逻辑待实现。 |
| `frontend/src/App.vue`、`frontend/src/preview.js`、`frontend/src/RequestWorkbench.vue`、`frontend/src/TaskComposer.vue` | Vue3 本地预览采用苹果官网式视觉，含八个业务页面。请求和任务支持逐字段与整段 JSON 录入，参数、变量支持批量编辑。已按本机 CLI 帮助扩展测试目标、循环数据、超时、错误处理、变量、报告、网络与集成配置。网站环境、资产、实验方案、回归和检查记录可新增编辑。演示响应按填写的断言计算结果，任务保存配置快照并支持三种报告导出和预览 JSON 导入复测。界面保留演示标识，真实工具执行及云端操作待接入。 |
| `docs/分工和提交要求.md`、`docs/前后端接口契约检查报告.md` | 分工规定十项功能、六人交付和课程验收。检查报告记录了原稿的十项接口问题。 |
| `docs/前后端接口契约.md` | 已按检查报告补写，覆盖资源与任务、调试与断言、统一指标、两类对比、报告导入导出和验收证据。第 8 节为已确认的四项约定。 |

**接续位置：计划与契约已确认，前端表单扩展已完成本地验证。** 已验证字段与 JSON 切换、批量参数、断言结果、环境变量继承、实验配置保存、任务快照及 JSON 归档恢复，三轮任务显示对应的三轮计数。前端构建通过。1、2 号下一步用契约中的请求和响应样例同步接口定义、前端类型与示例，3 号交付可独立执行的小场景，供首次真实任务联调。第二网站仍待确定。业务接口、正式实验数据和验收结论均待交付。
