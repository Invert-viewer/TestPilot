## 2. 联调采用的接口约定

以下按检查报告编号归纳已写入契约的内容。请求体、响应样例及验收步骤见 `docs/前后端接口契约.md`。

| 审查项 | 修订与验证要点 |
|---|---|
| C-01、C-02　目标与环境 | 初始目标越界返回 403，不建立记录。重定向越界或超限则返回 200 并保存失败记录，分别标记 `TARGET_REDIRECT_NOT_ALLOWED`、`TARGET_REDIRECT_LIMIT_EXCEEDED`。环境保存时校验允许范围和网站同源性，拼接请求路径保留环境地址的路径前缀。 |
| C-03、C-04　断言与计数 | 分开定义断言配置和 `AssertionResult`。结果包含预期值、实际值及通过、失败或跳过状态。任务与报告共用总数、通过、失败、跳过、未评估五个计数。完整结果的后四项之和等于总数，未知用 `null`，已知为空用 0。 |
| C-05、C-06　列表与状态 | 分页列表返回 `items/page/pageSize/total`，环境和体验记录返回数组，日志按游标读取。排队、运行及取消中继续轮询，遇 `FINISHED / CANCELLED / ERROR` 停止。已完成任务另读 `outcome` 判断测试结论。 |
| C-07、C-08　提交与请求头 | 创建和复测任务使用 `Idempotency-Key`。同键同内容返回原任务，同键异内容返回 409。从 cookies 字段生成 Cookie，保留头与冲突的正文类型返回字段级错误。 |
| C-09、C-10　历史与预览 | 调试历史支持 `outcome` 筛选。预览成功返回自包含 HTML，失败返回 JSON。任务存在且报告未就绪返回 409，任务不存在返回 404。 |

1、2 号以同一份契约同步 OpenAPI 定义、前端类型与示例及 Apifox 调试请求，核对枚举、可空字段、空列表和报告下载格式。
