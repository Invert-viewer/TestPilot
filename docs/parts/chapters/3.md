## 3. 平台功能与验收

| 功能 | 可演示的验收结果 |
|---|---|
| 1．网站与环境 | 登记徐州工程学院官网（https://www.xzit.edu.cn/）及待确定的第二个高校官网。每站保存可测试范围、环境与可比页面，切换后可核对实际目标。 |
| 2．HTTP 调试 | 配置 URL、方法、参数、Header、Cookie 和请求体，发送后查看状态码、响应头、正文及耗时，能按结果筛选历史请求。 |
| 3．用例、场景与断言 | 复用请求清单、环境变量、Apifox 场景及 JMeter 计划。按响应类型验证状态码、正文、真实存在的结构化字段或耗时，可查看失败断言的预期值和实际值。 |
| 4．多工具执行 | 前端选择网站、场景与工具，Spring Boot 调用 Apifox CLI 或 JMeter，保存任务 ID、工具版本和实际执行配置。 |
| 5．参数实验 | 保存并重复执行多组方案。Apifox CLI 可调循环次数与请求间隔，JMeter 按计划配置线程、升压和时长。 |
| 6．任务与日志 | 可提交、查状态、取消和复测任务。通过退出码、日志、请求与断言明细区分目标请求失败、断言失败和工具故障。 |
| 7．结果展示 | 表格和图表显示样本数、平均及分位响应时间、吞吐量、错误率和断言通过率，标明单位、分母和缺失值。 |
| 8．同工具跨网站 | 对两个网站的同类页面应用相同参数档位并重复运行。能按档位查看两站数据表、趋势曲线及对应原始任务。 |
| 9．同网站跨工具 | 对同站同一组请求分别运行 Apifox CLI、JMeter，比较可比指标，并用操作记录评价工具的配置效率、断言、报告与集成能力。 |
| 10．归档与复测 | 历史任务可查看配置、日志、原始报告和截图，对照复测前后差异。支持导出 `.html`、`.md`、`.json`。重新导入 JSON 后可核对网站、环境、资产、断言和参数，再次运行相同场景。日志和导出文件中的令牌等敏感值须脱敏。 |
