## 5. 六人交接与实施顺序

| 成员 | 交付与答辩演示 | 课程报告 |
|---|---|---|
| 1 号 · 组长 | 与 2 号定稿契约，负责架构、数据保存、项目与任务管理、工具调度。演示从提交到真实报告回传及故障定位。 | 第 2 章后端，第 1、7 章及全文整合 |
| 2 号 · 前端 | 用 Vue3 对接配置、调试、任务、日志、结果、历史与比较页面。演示选择环境、执行任务、查看报告和曲线。 | 第 2 章前端 |
| 3 号 · 测试资产 | 将勘查清单、变量、可运行场景 ID 或导出文件及运行说明交给 4、5 号。演示环境切换和基础请求。 | 第 3 章，补充第 6 章 |
| 4 号 · 实验 | 与 3 号核对两站业务，编写 JMeter 对照计划。演示参数表、两类实验的原始记录与结论。 | 第 4、6 章 |
| 5 号 · 断言与回归 | 为正常、异常、边界用例编写预期结果。演示一次断言失败的定位、复测及前后差异。 | 第 5 章 HTTP 测试，补充第 6 章 |
| 6 号 · 页面与平台验收 | 从首次联调开始核验导航、显示、参数校验、任务状态、失败提示、报告与历史。演示一个实际问题及复测证据。 | 第 5 章页面与平台验收 |

1. **方案与契约。** 组长已确认计划及四项接口约定，契约已按检查报告补写。跨网站实验前由组长选定第二网站，3、4 号核实可比页面和参数档位。
2. **跑通真实任务。** 3 号先独立跑通一个官网小场景，再由 1、2 号接入。验收时从 Vue3 提交任务，按同一任务 ID 核对 CLI 日志、持久化结果和前端报告。
3. **完成个人模块。** 接入 JMeter，完成 HTTP 调试、断言回归与页面检查。6 号验证重复提交、异常提示、报告预览和 JSON 导入复测。
4. **执行正式对比。** 4 号按第 4 节完成两类实验，用真实数据生成图表，标注参数差异与限制。
5. **整体验收与答辩。** 六人分别提交可复现成果、设计说明、用例或验收步骤、原始证据、真实问题与解决过程、章节和演示片段。组长汇总七章报告，并核对十项功能与两类对比的证据。
