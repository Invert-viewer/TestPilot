# 4 号：参数实验与多工具对比

## 操作步骤

1. 从 3 号取得统一请求清单、场景标识和可比页面，从 1 号取得可访问后端及真实资产列表。
2. 在「实验对比」新增方案，先选择问题：同工具跨网站，或同网站跨工具。填写实际网站、scenarioKey、参数档位和重复次数。
3. 当前真实 Apifox 执行支持循环次数、请求间隔、请求超时。先确定低频参数方案，在「任务与报告」逐次提交实际任务，并记录各档位的 taskId。
4. 跨网站实验要求两个同类网站各自有登记资产和真实样本。仅在本地网站页新增网站不会改变 CLI 目标，也不能构成对照网站的真实样本。
5. 跨工具实验必须固定网站、环境、请求语义、断言和执行条件。当前后端尚未接入 JMeter；不要把 JMeter 草稿或本地模拟任务当成真实对照组。
6. 将已完成任务关联到实验方案，选择该方案并点“核对来源任务”，检查网站、工具、场景、档位和各组重复次数。
7. 对缺少对照网站、JMeter、完整报告或重复样本的提示逐项补证；缺项存在时只交付方案和缺项清单，不生成实验结论。
8. 在“按来源任务记录工具体验”中选择已关联任务，填写准备步骤、配置耗时、执行用时、断言能力、报告体验与证据。未知耗时留空，不能用 0 代表未知。
9. 共享方案时导出本地配置，另交付真实 taskId 和报告。对接同一后端后重新核对引用；浏览器里的实验方案不会自动同步。

## 统计与交付

保留网站、环境、工具、场景、档位、重复次数、日期和来源任务。平均/P95 要注明单位与样本，未知用“—”。当前 errorRate 的后端口径不能保证排除纯断言失败，吞吐量为 null，不能据此形成性能优劣结论。串行循环也不是并发压测。
