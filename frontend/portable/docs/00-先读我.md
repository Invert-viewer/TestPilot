# TestPilot 前端交接包

## 三步打开

1. 将压缩包**全部解压**到自己的文件夹。不要在压缩包预览窗口里直接运行。
2. 双击 `启动前端.bat`，或英文名的 `START.bat`。
3. 浏览器会打开「请求调试」，可以直接填写 URL 运行本地模拟；执行已登记场景请点击「新建任务」。如果没有自动打开，复制启动窗口显示的地址到浏览器。

这个 Windows x64 交接包已经包含构建后的 Vue 页面和 Node 运行时。**打开前端不用安装 Node、npm、Java、MySQL，也不需要联网下载依赖。** 第一次看到的默认地址为 `http://127.0.0.1:5173/#/debug`；如果端口已占用，脚本会自动顺延，以窗口显示的地址为准。

前端服务运行时请保留命令行窗口；按 Ctrl+C 或关闭窗口停止。重开时重复双击脚本即可。

## 必须区分的两件事

- **打开、操作前端**：本包可以独立完成。网站环境、资产草稿、请求模拟、回归配置、检查记录等本地功能可用。
- **真实执行 Apifox 任务**：必须另外连接已经启动的 Spring Boot 后端。后端、数据库、Apifox CLI、登录凭据及被测网站不包含在这个前端包里。

未连接后端时，概览、登记场景、任务、报告和真实实验来源会显示真实连接错误；页面不会自动替换为演示任务。可以继续操作清楚标记为本地演示的页面。

## 接入后端

1. 向 1 号（后端与集成负责人）取得**Spring Boot 的地址**，例如 `http://192.168.1.20:8080`。
2. 用记事本打开包根目录的 `config.json`，只修改 `backendUrl`，保存后重启启动脚本。

```json
{
  "port": 5173,
  "backendUrl": "http://192.168.1.20:8080",
  "openBrowser": true,
  "startPage": "/#/debug"
}
```

地址只填协议、主机和端口，不要追加 `/api/v1`，也不要填用户名、密码或令牌。`127.0.0.1` 代表**当前运行前端的这台电脑**；如果后端在部署者电脑上，就要填部署者提供的可访问地址。`backendUrl` 不是被测网站地址。

当前便携服务只在自己的电脑上监听，不会自动把前端公开到局域网。每个人分别运行自己的前端，通过配置连接同一个后端即可。

## 平台数据怎么共享

真实任务和报告存于所连接的后端。多人使用同一后端时，可以共享**实际 taskId** 来打开同一个任务。

本地演示配置保存在各自浏览器中，按「浏览器 + 前端地址/端口」区分，**不会自动同步给其他人**。共享配置时，使用页面的导出 JSON 和整段 JSON 录入，并在接收端重新核对网站、环境和资源引用。新建资源可能生成新的本地 ID，不能假定原 ID 自动保持。

默认从 5173 开始选端口。如果已有服务占用而改用了新端口，新地址里的本地演示数据可能是空的；原端口的数据没有被删除。

先看 `docs/整体流程.md`，再按自己的编号阅读 `docs/交接/` 中的说明。
