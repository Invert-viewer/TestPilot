# 2 号：平台前端与结果展示

## 直接运行和联调

1. 完整解压本包，双击启动前端.bat。先按整体流程熟悉八个入口与来源标签。
2. 从 1 号取得 Spring Boot 地址，在包根 config.json 中修改 backendUrl 后重启。该配置仅影响便携启动服务。
3. 核对「概览」和「测试资产」的真实数据，再选择登记场景创建任务，检查状态、增量日志、失败断言和报告。
4. 刷新当前任务，复制带 taskId 的页面地址重开。接收者需要连接同一个后端；如果前端端口不同，只复制实际 taskId 后用“打开任务”。
5. 验证请求和任务的表单/JSON 双向切换。未完成必填项也应能返回表单；非法 JSON 不得覆盖已有配置，切回后原文仍在。
6. 验证鼠标停在表格上仍可纵向滚动；窄屏表格可横向滚动；长弹窗的内容和保存操作可达。

## 继续修改源码

源码在 `source/frontend`，本包的 runtime/node.exe 仅供开箱运行，没有附带 npm。开发时在自己的电脑准备 Node/npm；本次构建使用 Node v26.12.1 和 package-lock.json 中的锁定版本。

```powershell
cd "你的解压目录\source\frontend"
npm.cmd ci
npm.cmd run dev
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

源码开发的后端代理在 vite.config.js；包根 config.json 不会自动修改 Vite 的代理。运行 test:e2e 需要本机 Edge 和对应的前后端服务，其中真实任务用例会新增一次只读 CLI 任务。

若要重新制作便携包，可使用源码中的 scripts/package_portable.py，并指定本包的 runtime/node.exe 作为运行时来源。需要 Python，先运行 build；具体命令见 source/README.md。
